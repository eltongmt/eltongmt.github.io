Selected Works

Wheeled Robot Pick Up Task Simulation

  • Developed code to generate an end-effector screw trajectory based on the cube’s initial and final positions.
  • Implemented a kinematic task-space PI control law to compute the twist corresponding to the planned trajectory.
  • Calculated target wheel and joint speeds using the base and arm Jacobians, applying a weighted least-squares approach.
  • Tuned PI controller gains (kp​ and ki) to minimize error, overshoot, and oscillations for optimal performance.

Tracking and Following Objects with NAO robot

  • Used Softbank Robotics' NAO SDK along with NumPy and openCV to retrive images, detect objects, and commad head angles to follow the detected object.
  • Images were retrived from NAO using a wired connection and Object Detection was based on a custom trained YOLO model run off-device .

Rapidly Expanding Random Tree for Path Planning

  • Wrote to code to use RRT to find a path from a list of obstacles (circles), a starting position, and a goal location.
  • The code consists of a custom implementation of the RRT algorithm using a graph class and NumpPy.
  • Each functionality of the algorith such as random sampling was tested using unittest.

Software Development for Timeseries Analysis

  • Wrote code to visualize, manipulate, and analyize behavioral timeseries data in MATLAB.
  • Code was throughly documented and was organized around existing functionality.
  • Usage of Deep Learning, Image Processing, Computer Vision, Signal Processing, and Machine Learning Toolbox.

Object Clustering from Ego-Centric View

  • Visualized clusters of 27 objects from Ego-Centric view across 20+ experiment particpants.
  • Object images where extracted using a custom YOLO model, which was applied to extracted frames of the participant's Ego-Centric video.
  • Resnet was used embbed the object images, multi dimensional scaling was used to reduce the embedding to two dimensions .
  • Created unsurpervised clustered using K-means and compared the clustering results to grounth truth clusters.
